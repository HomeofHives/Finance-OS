Finance-OS is a production-oriented personal finance management platform built as a pnpm monorepo.

The workspace is split into four packages:

- `apps/frontend` — React + Vite single-page application (TanStack Router, Tailwind CSS v4, Framer Motion)
- `apps/backend` — Fastify API (Mongoose, Zod-validated environment configuration)
- `packages/ui` — shared design tokens and shadcn/ui components, consumed by the frontend
- `docs` — this documentation site, built with Astro + Starlight

See the repository `README.md` for setup, environment configuration, and validation commands.
